# ♟ Chess Capture Detection – Python Project

This Python program determines **which black pieces a single white piece can capture** on a simplified chessboard.  
The user places:

- **1 white piece**
- **1–16 black pieces**

The program validates all inputs, visualizes the board using UTF-8 chess symbols, and applies real chess movement rules to compute valid captures.

---

## 🔧 Features

- Input validation for chess pieces and board positions  
- Supports all standard pieces: **pawn, knight, bishop, rook, queen, king**  
- Prevents overlapping pieces  
- Beautiful UTF-8 chessboard printing  
- Accurate capture logic for each piece  
- Fully modular design (mini-tasks)
