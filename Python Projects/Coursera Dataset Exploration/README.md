# Coursera Course Dataset Analysis

##Project Overview
This project presents an exploratory data analysis (EDA) of the Coursera Course Dataset. The goal of the analysis is to examine course ratings, enrollment patterns, certificate types, difficulty levels, and organizational performance using Python data analysis and visualization tools.
The project demonstrates practical data cleaning, exploratory analysis, and visualization techniques, with a focus on drawing meaningful insights from real-world data.

## Objectives
- Load and explore the Coursera Course Dataset using Pandas
- Perform data cleaning and preprocessing
- Conduct exploratory data analysis to identify patterns and relationships
- Visualize key insights using Matplotlib, Seaborn, and Plotly
- Interpret results and propose data-driven improvement suggestions

## Dataset
- Source: Coursera Course Dataset (Kaggle)
- Description: The dataset contains information about online courses offered on Coursera, including course ratings, enrollment counts, certificate types, difficulty levels, and course providers.

## Tools and Libraries
- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
